# Throne VPN для Noctalia

Управление [Throne](https://github.com/throneproj/Throne) из нативного виджета и прикреплённой панели Noctalia. Выбор VPN-профилей, подключение через TUN и просмотр сохранённых метрик без открытия окна Throne.

[English](README.md)

## Возможности

- Подключение и отключение профилей, повторное подключение последнего профиля.
- Последние сохранённые ping, download/upload и накопленный трафик.
- Сортировка по скорости скачивания, поиск и прокрутка списка.
- Иконка, отражающая состояние подключения.
- Нативная панель с темой и настройками расположения Noctalia.

## Зависимости

| Зависимость | Требование |
| --- | --- |
| [Noctalia](https://noctalia.dev/) | Нативная Noctalia 5 с API плагинов 24 или новее |
| `python3` | Python 3.11 или новее, только стандартная библиотека |
| [Throne](https://github.com/throneproj/Throne) | Сборка с поддержкой API; целевая версия — `1.4.0-beta.4` |
| [`thronectl`](https://github.com/throneproj/Throne-api) | Целевая версия — `v0.2.0`; доступен через PATH или указанный путь к файлу |

Способ установки зависимостей зависит от дистрибутива. Плагин не устанавливает и не обновляет их.

Throne должен быть запущен с включённым API, настроенными профилями и правами ядра для TUN. Нужен существующий файл API-ключа, доступный пользователю графического сеанса. Настройка API описана в [документации Throne](https://throneproj.github.io/advanced/api/), права TUN — в [permissions.md](throne-vpn/permissions.md).

## Установка

Добавление GitHub-репозитория в источники Noctalia:

```
noctalia msg plugins source add throne-vpn git https://github.com/lonefrogg/noctalia_throne_plugin.git
noctalia msg plugins enable lonefrogg/throne-vpn
```

Для локальной копии или распакованного ZIP команды выполняются из корня проекта, где находится `catalog.toml`:

```
noctalia msg plugins source add throne-vpn-local path "$PWD"
noctalia msg plugins enable lonefrogg/throne-vpn
```

При использовании локального источника его папка должна оставаться на месте.

## Использование

1. Открыть **Настройки → Плагины → Throne VPN** и указать адрес API, файл ключа и исполняемый файл thronectl.
2. Добавить на панель виджет **Throne VPN** через выбор виджетов. Полный ID: `lonefrogg/throne-vpn:bar`.
3. Открыть меню и выбрать профиль для подключения через TUN.

Сервис `backend` запускается вместе с плагином и автоматически обслуживает виджет `bar` и панель `panel`.

| Управление | Действие |
| --- | --- |
| ЛКМ по виджету | Открыть или закрыть меню |
| ПКМ по виджету | Закрыть меню |
| Нажатие на профиль | Подключить профиль |
| **Disconnect** | Отключить текущее соединение |
| **Last profile** | Подключить последний использованный профиль |
| **Refresh** | Перечитать сохранённые метрики Throne |
| Колесо или тачпад | Прокрутить список |
| Escape или крестик | Закрыть меню |

Открытие панели через IPC:

```
noctalia msg panel-toggle lonefrogg/throne-vpn:panel
```

Профили сортируются по сохранённой скорости скачивания по убыванию. Профили без замера идут после измеренных, с неудачным тестом — в конце. Скорость отображается в Mbps, задержка — в миллисекундах, `Σ` обозначает накопленный трафик.

## Настройки

Общие настройки виджета и панели доступны в **Настройки → Плагины → Throne VPN**.

| Параметр | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `api_address` | string | `127.0.0.1:9095` | Адрес API Throne |
| `api_key_file` | file | Не задан | Путь к существующему файлу ключа, а не сам ключ |
| `thronectl_path` | string | `thronectl` | Имя исполняемого файла или полный путь; поддерживается `~` |
| `poll_seconds` | int | `3` | Интервал обновления состояния, от 2 до 60 секунд |

Прикреплённое или плавающее расположение и открытие рядом с указателем настраиваются в параметрах панели Noctalia.

## Обновление

Для Git-источника:

```
noctalia msg plugins update throne-vpn
```

Локальный источник использует файлы своей папки и не скачивает обновления.

## Особенности работы

- Профилями, подписками и маршрутизацией управляет Throne. Выбранный маршрут сохраняется.
- Плагин читает сохранённые результаты тестов. Обновление меню не запускает замер скорости.
- Иконка отражает состояние, сообщаемое Throne: TUN, режим прокси или проблемы подключения.
- Отключение плагина останавливает опрос, сохраняя активное VPN-соединение.

Сервис запускает `python3` со встроенным `backend.py`, который вызывает `thronectl` через массивы аргументов. thronectl обращается к указанному API, по умолчанию локальному, и читает файл ключа. Помощник не читает и не выводит значение ключа. Подключение может включать TUN; плагин не выдаёт привилегии и не изменяет профили, маршруты или подписки.

Помощник создаёт приватный файл блокировки в `$XDG_RUNTIME_DIR/noctalia-throne-vpn` или `~/.cache/noctalia-throne-vpn`. Настройки сохраняет Noctalia. Телеметрия и загрузка исполняемого кода во время работы отсутствуют.
